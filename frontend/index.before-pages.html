Let AI agents spend crypto safely.

A smart contract enforces the owner's spending rules on-chain, so a hacked or tricked agent can only ever lose a bounded amount.

1Owner sets the rules
2AI agent spends
3Firewall blocks the rest
  1. Normal purchase ALLOWED
    The agent buys something small (0.001 ETH) from the approved merchant — the firewall lets it through.
  2. Overspend BLOCKED
    The agent tries to send 0.1 ETH, which is over the per-payment limit — the contract refuses before any money moves.
  3. Prompt injection BLOCKED
    A tricked agent sends 1 ETH to an unknown address — not an approved recipient, so it is blocked.
  4. Owner freezes the agent BLOCKED
    Connect the owner wallet, press Freeze agent, then run a payment — the next payment is blocked instantly.
